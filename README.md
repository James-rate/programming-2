# Console Card Game Draft

Three student-edited console card-game source files with dealing and battle logic.

Incomplete snapshot: compatible CardLibrary, Deck, In and WeaponStyle dependencies were not found with these edited files. The available starter Deck does not implement the methods used here. This branch preserves the three files without inventing or repairing missing code.

## Source and structure

Original source and resources are under `src/`, with their contents and line endings preserved. Added files contain repository documentation, build instructions and ignore rules.

Source context: Locally edited Card.java, Dealer.java and Player.java files.

## Status

This is an incomplete source fragment, not a standalone runnable application. Missing dependencies are deliberately not fabricated.

## Verification

See [VALIDATION.md](VALIDATION.md) for compilation or syntax-check results. Application windows, interactive gameplay, accounts and network services were not run during this archival work. Existing coursework helpers and assets remain part of their original learning projects.
