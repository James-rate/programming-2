Source context: Local exercise-4 Java practice.

## Build and run

The Windows build helper expects a Java 8 JDK. The JavaFX runtime is not bundled with these sources.

```powershell
.\build.ps1 -JdkPath 'C:\path\to\jdk8'
java -jar build/project.jar
```

Default main class: `Hello`. Use `-MainClass` to select a different entry class when the exercise contains several programs.
