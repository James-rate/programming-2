# Python Number to Words

An interactive Python exercise converting integers to English words and Roman numerals.

Use positive integers from 1 to 999 and -1 to exit. Input validation and zero/negative-number edge cases are incomplete in the preserved implementation. Its timing and topic match the early course materials, although the file does not record a course code.

## Source and structure

Original source and resources are under `src/`, with their contents and line endings preserved. Added files contain repository documentation, build instructions and ignore rules.

Source context: Original home-1.zip Python exercise.

## Run

Requires Python 3 and only the standard library.

```text
python src/NumberToWords.py
```
