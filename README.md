# Module 0 Java Basics

Four introductory Java console exercises practising main methods and printed output.

Available entry classes: Program1, Program2, Program3 and Program4. These local Java exercises have no explicit course identifier, so their exact course affiliation is unconfirmed.

## Source and structure

Original source and resources are under `src/`, with their contents and line endings preserved. Added files contain repository documentation, build instructions and ignore rules.

Source context: Local Module0 Java exercises.

## Build and run

The Windows build helper expects a Java 8 JDK. The JavaFX runtime is not bundled with these sources.

```powershell
.\build.ps1 -JdkPath 'C:\path\to\jdk8'
java -jar build/project.jar
```

Default main class: `Program1`. Use `-MainClass` to select a different entry class when the exercise contains several programs.
